# EchoMind-AI
EchoMind AI

EchoMind AI is a voice and text-based intelligent assistant powered by a local large language model (Ollama). It understands natural language commands and performs real-world actions like opening websites, searching the web, and executing system tasks.

🚀 Features
🎤 Voice command support
⌨️ Text-based input
🧠 AI-powered understanding using Ollama LLM
🌐 Open websites (YouTube, Google Drive, etc.)
⚡ Fast and offline AI processing
🔊 Voice response system (optional upgrade)
🏗️ System Workflow

Voice/Text Input→Speech-to-Text→Ollama AI Model→Intent Detection→Action Execution

🧰 Tech Stack
Python 🐍
SpeechRecognition 🎤
pyttsx3 🔊
Ollama (LLM) 🧠
Webbrowser 🌐
Requests 📡
⚙️ Installation
1. Clone repository
git clone https://github.com/your-username/echomind-ai.git
cd echomind-ai
2. Install dependencies
pip install speechrecognition pyttsx3 pyaudio requests
3. Install Ollama

Download from:
👉 https://ollama.com

Run a model:

ollama run llama3
▶️ Run Project
python main.py
